# Império Cutelaria – Site

- **Cliente:** Império Cutelaria
- **Site:** site institucional da cutelaria artesanal
- **Publicado em:** https://imperiocutelaria.imaguiar.com.br/ (em configuração)
- **GitHub Pages:** https://raiugami.github.io/imperio-cutelaria/

## Descrição

Site de uma página em HTML, CSS e JavaScript puros, sem ferramentas de build. O conteúdo fica visível sem JavaScript; os efeitos só realçam a página. Respeita `prefers-reduced-motion` e é pensado para celular (360 e 412 px).

## Tecnologias

- HTML5
- CSS3
- JavaScript (sem bibliotecas por enquanto)
- GitHub Pages (publicação pela branch `main`)

## Estrutura de pastas

```
index.html   página principal
styles.css   estilos
script.js    comportamento
CNAME        domínio customizado do GitHub Pages
README.md    este arquivo
```
